# نتیجهٔ تفکیک منبع EduManager

در این بازسازی، کد اجرایی تک‌فایلی به درخت منبع موضوعی و خروجی ساخت قابل تکرار تبدیل شد.
مرجع ویرایش برنامه `src/` است؛ HTML فقط پوسته را نگه می‌دارد و فایل‌های `assets/`
برای انتشار تولید می‌شوند. فایل‌های خروجی بزرگ، bundle هستند و کد دست‌نویس مرجع محسوب نمی‌شوند.

## تفکیک انجام‌شده

- ۱۴۲ فایل منبع JavaScript/CSS؛ بزرگ‌ترین واحد منبع ۷۸۹ خط.
- ۲۸ خروجی JavaScript/CSS با ترتیب ثبت‌شده در `source-map.json`.
- تفکیک صفحات، نمره‌دهی، دانش‌آموزان، جلسات، برنامهٔ هفتگی، گزارش‌ها و ابزارهای رابط.
- تفکیک منبع دوره‌ها، پشتیبان، پیش‌نویس، تاریخچه، undo، تنظیمات و هم‌زمانی.
- ماژول‌های مستقل برای اتصال IDB، codec، تراکنش اتمیک، اعتبارسنج‌ها و محاسبات دامنه.
- تفکیک گزارش دوره‌ای و فرم درس در scopeهای خصوصی موجود.
- تقسیم استایل‌ها با حفظ cascade؛ فونت‌های آفلاین حفظ شده‌اند.
- تقسیم سناریوهای مرورگر در `audit/flows/` و حذف تزریق متن کد به runner.

## ابزار توسعه و کنترل انتشار

- `npm run build`: تولید خروجی، فهرست cache و شناسهٔ نسخه از محتوای کل انتشار.
- `npm run build:check`: رد خروجی قدیمی و منبع ثبت‌نشده، بدون تغییر فایل.
- `npm run dev`: سرور محلی روی loopback؛ فقط فایل‌های انتشار را سرو می‌کند.
- `npm test`: تست واحد، کنترل ساخت، قرارداد داده/asset و تست کامل مرورگر/PWA.
- بدون dependency خارجی برای build یا تست واحد؛ مرورگر Edge برای تست یکپارچه لازم است.

## صحت و حدود تغییر

اجرای نهایی `npm test`: ۴۳ تست واحد و ۲۶۰ تست مرورگر موفق، صفر شکست.
`npm run build:check` همگامی ۲۸ خروجی با ۱۴۲ فایل منبع را تأیید کرد.
سرور محلی برای HTML/CSS/JavaScript و عدم انتشار مسیرهای منبع بررسی شد.

عملیات داده و schema کاربران حفظ شده‌اند. پیش‌نویس نامعتبر در backup جدا می‌ماند؛
کارنامهٔ قدیمی بدون مؤلفهٔ ساختگی خوانده می‌شود. تعارض revision، undo و restore
همچنان در تراکنش‌های واقعی آزمایش می‌شوند. محتوای CSS با همان ترتیب به خروجی می‌رود.

منابع legacy و workspace هنوز bindingهای مشترک سازگار دارند و با ترتیب manifest
ترکیب می‌شوند؛ این کار مهاجرت به framework جدید یا تبدیل سراسری به ES module نیست.
handlerهای inline نیز برای حفظ رفتار موجود باقی‌اند. تست دستگاه واقعی Android/iPhone
و ممیزی یک بازنویسی مستقل در پوشه‌ای دیگر، خارج از این نتیجه‌اند.

راهنمای ساختار: `src/README.md`، راهنمای آزمون: `audit/README.md`، قرارداد معماری:
`docs/ARCHITECTURE.md`. نتیجهٔ هر اجرای تازه از مسیر `resultFile` چاپ‌شده در تست قابل بررسی است.
