پاسخ‌نامهٔ جداگانهٔ دبیر — ارسال نشود

آزمون 1 — طراحی وب و برنامه‌نویسی — یازدهم — آزمایشی

  1. کد زیر را بخوانید و مقدار نهایی total را همراه دلیل بنویسید: let total = 0; for (let i = 1; i <= 3; i++) { total += i; }

    پاسخ: مقدار نهایی 6 است؛ حلقه اعداد 1، 2 و 3 را جمع می‌کند.

    پاسخ باید تعداد تکرارها و نتیجهٔ جمع را توضیح دهد.

  2. در JavaScript، خروجی عبارت 2 + 3 * 4 برابر است با

    پاسخ: 14

    ضرب پیش از جمع انجام می‌شود؛ 2 + 12 = 14.

  3. Explain the difference between HTML structure and CSS presentation. Give one short example for each.

    پاسخ: HTML defines elements such as headings and paragraphs; CSS controls presentation such as color and spacing. Example: <h1>Title</h1> and h1 { color: blue; }.

    Accept equivalent correct examples; assess the distinction, not memorized wording.

  4. برای فرم ثبت نام هنرجو، یک طرح بررسی ورودی پیشنهاد کنید. الف) نام خالی چه پیامی داشته باشد؟ ب) ایمیل نامعتبر چگونه اعلام شود؟ ج) چرا خطا نباید فقط با رنگ مشخص شود؟ د) نقش Client و Server را جدا توضیح دهید.

    پاسخ: نام و ایمیل باید با پیام روشن کنار فیلد بررسی شوند؛ پیام متنی و ارتباط دسترس‌پذیر با فیلد لازم است. کنترل سمت کاربر برای بازخورد سریع و سمت سرور برای اعتبارسنجی قابل اتکا انجام می‌شود.

    برای هر یک از چهار بخش پاسخ مستقل ارزیابی شود.

  5. برای ایجاد پیوند به صفحهٔ دیگری در HTML از کدام عنصر استفاده می‌کنیم؟

    پاسخ: 1) a

    عنصر a همراه ویژگی href برای پیوند استفاده می‌شود.

  6. اگر ورودی یک فرم در مرورگر بررسی شود، بررسی همان ورودی در Server دیگر لازم نیست.

    پاسخ: غلط

    کنترل مرورگر قابل دور زدن است؛ سرور باید دادهٔ ورودی را بررسی کند.

  7. Which CSS property changes the text color?

    پاسخ: 2) color

    The color property sets the foreground text color.

  8. در فرم ثبت‌نام، چرا اعتبارسنجی سمت سرور نیز لازم است؟

    پاسخ: 4) چون درخواست می‌تواند بدون اجرای اعتبارسنجی مرورگر مستقیماً به سرور ارسال شود و دادهٔ ورودی باید دوباره بررسی شود.

    اعتبارسنجی مرورگر برای تجربهٔ کاربر مفید است، اما مرز امنیتی قابل اتکا نیست.

  9. در CSS، انتخابگر .notice عناصر دارای class برابر notice را انتخاب می‌کند.

    پاسخ: صحیح

    نقطه پیش از نام، انتخابگر کلاس را مشخص می‌کند.

  10. In CSS, the ........ property sets the space inside the border of an element.

    پاسخ: padding

    Padding is inside the border; margin is outside it.

  11. HTML is a database management system.

    پاسخ: غلط

    HTML describes document structure; it is not a database management system.

  12. برای تعیین مقصد پیوند در عنصر a از ویژگی ........ استفاده می‌کنیم.

    پاسخ: href

    نمونه: <a href="lesson.html">درس</a>

آزمون 3 — داده، رایانه و شبکه — یازدهم — آزمایشی

  1. The device that forwards packets between networks is called a ........ .

    پاسخ: router

    Accept router, regardless of capitalization.

  2. جدول Students دارای ستون‌های student_id، full_name و grade است. دستور SQL نمایش نام هنرجویان پایهٔ 11 را بنویسید؛ فرض کنید grade عددی است.

    پاسخ: SELECT full_name FROM Students WHERE grade = 11;

    تفاوت حروف بزرگ و کوچک کلیدواژه‌ها و فاصله‌های اضافی در ارزیابی نادیده گرفته شود.

  3. در SQL، برای خواندن رکوردها از جدول از دستور ........ استفاده می‌شود.

    پاسخ: SELECT

    SELECT برای بازیابی داده کاربرد دارد.

  4. Explain why a backup should be tested by restoring it in a separate environment. Do not overwrite the original data in your proposed test.

    پاسخ: A successful backup operation alone does not prove recoverability. Restore a copy into an isolated environment and verify records and integrity without modifying the source.

    Assess isolation, successful restore and data verification.

  5. در جدول هنرجویان، ستون student_id می‌تواند برای تفکیک دو هنرجوی هم‌نام استفاده شود.

    پاسخ: صحیح

    شناسه باید یکتا باشد؛ نام افراد الزاماً یکتا نیست.

  6. کدام گزینه برای شناسایی یکتای هر رکورد در یک جدول رابطه‌ای مناسب است؟

    پاسخ: 1) کلید اصلی

    کلید اصلی هر رکورد را به‌صورت یکتا مشخص می‌کند.

  7. A primary key uniquely identifies a row in a relational table.

    پاسخ: صحیح

    Primary key values uniquely identify rows.

  8. Which device forwards IP packets between different networks?

    پاسخ: 2) Router

    A router forwards packets between networks.

  9. برای محدودکردن رکوردهای خروجی SELECT بر اساس یک شرط از کدام بند استفاده می‌کنیم؟

    پاسخ: WHERE

    WHERE شرط انتخاب رکوردها را بیان می‌کند.

  10. در کارگاه، دو هنرجو نام یکسان دارند و ارتباط شبکه هم گاهی قطع می‌شود. ۱) برای جلوگیری از اشتباه در ثبت نمره چه شناسه‌ای پیشنهاد می‌کنید؟ ۲) هنگام قطع ارتباط، چرا نباید پیام «ذخیره شد» نمایش داده شود مگر ذخیره واقعاً تأیید شده باشد؟ ۳) یک روش امن برای بررسی بازیابی پشتیبان توضیح دهید.

    پاسخ: شناسهٔ یکتا و پایدار لازم است. پیام ذخیره باید مطابق نتیجهٔ واقعی باشد و خطا امکان تلاش مجدد بدهد. بازیابی ابتدا در محیط جدا و با کنترل صحت داده آزمایش شود.

    سه مؤلفهٔ هویت، صداقت وضعیت ذخیره و بازیابی ایمن مستقل ارزیابی شوند.

  11. برای جدول هنرجویان، کدام طراحی مناسب‌تر است؟

    پاسخ: 3) یک شناسهٔ یکتا برای هر هنرجو تعریف شود و نام کامل در فیلدی جدا ذخیره شود تا افراد هم‌نام قابل تشخیص باشند.

    هویت پایدار نباید به نام یا ترتیب نمایش وابسته باشد.

  12. داشتن نسخهٔ پشتیبان روی همان دیسک، به‌تنهایی در برابر خرابی کامل همان دیسک کافی است.

    پاسخ: غلط

    خرابی دیسک می‌تواند دادهٔ اصلی و پشتیبان روی همان دیسک را هم‌زمان از بین ببرد.
