# edu-manager

برنامه شخصی مدیریت کلاس و نمرات؛ آفلاین، بدون بک‌اند و با خروجی محلی JSON و TXT.

## فایل‌ها
- `EduManager.html`: تنها فایل اصلی برنامه؛ تمام منطق، استایل و رابط داخل آن است.
- `app.webmanifest` و `service-worker.js`: فایل‌های فنی نصب و اجرای آفلاین PWA.
- `index.html`: ورودی کوچک GitHub Pages؛ فقط به فایل اصلی هدایت می‌کند و کد برنامه را تکرار نمی‌کند.

## GitHub Pages
پس از بررسی و ارسال تغییرات توسط مالک، در Settings → Pages:
Source = Deploy from a branch، Branch = master، Folder = /(root).
نشانی مورد انتظار: https://saeid-pirzad.github.io/edu-manager/
فعال‌بودن لینک باید بعد از انتشار بررسی شود.

## نصب
لینک را بار اول با اینترنت باز کنید؛ تا نمایش «آماده اجرای آفلاین» صبر کنید.
در Chrome/Edge از نصب برنامه و در Safari آیفون از Share → Add to Home Screen استفاده کنید.
یک بار از آیکن نصب‌شده باز کنید و سپس قطع اینترنت را امتحان کنید.
نصب اولیه، نصب مجدد و به‌روزرسانی به اینترنت نیاز دارند؛ اجرای روزمره از نسخه ذخیره‌شده است.

## داده‌ها
اطلاعات روی همان دستگاه و پروفایل مرورگر است؛ همگام‌سازی خودکار نداریم.
پشتیبان JSON را منظم ذخیره کنید. فایل‌های نمره و پشتیبان را به مخزن عمومی نفرستید.
نسخه محلی فایل و نسخه GitHub Pages محل ذخیره جدا دارند؛ انتقال با پشتیبان و بازیابی است.

## به‌روزرسانی
با تغییر HTML یا manifest، مقدار VERSION در service-worker.js را هم تغییر دهید.
نسخه جدید فقط پس از دریافت کامل آماده می‌شود. پیش از اعمال آن، ویرایش‌های معتبر پنجره فعلی ذخیره می‌شوند؛ فقط همین پنجره بازخوانی می‌شود. پنجره‌های دیگر خودکار بازخوانی نمی‌شوند.

## فونت آفلاین
فونت IRANSans در سه وزن معمولی، متوسط و ضخیم از فایل‌های محلی مالک داخل HTML جاسازی شده و هیچ CDN یا دانلود زمان اجرا ندارد.
