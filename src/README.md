# کد منبع EduManager

کدهای قابل ویرایش برنامه در این پوشه‌اند. فایل‌های JavaScript و CSS در `assets/`
خروجی ساخت هستند؛ مستقیم ویرایش نشوند. `npm run build` آن‌ها را تولید می‌کند.

## مسیرها

| مسیر | مسئولیت |
| --- | --- |
| `domain/` | محاسبهٔ نمره، تقویم، CSV، رمز، پیش‌نویس و قواعد امن داده |
| `data/` | schema، اتصال IndexedDB، codec رکورد، برنامهٔ ذخیره و تراکنش اتمیک |
| `validation/` | اعتبارسنجی پشتیبان کامل، کارنامهٔ ثابت و undo |
| `ui/` | تقویم، پنجره‌ها، پوسته و فرم تنظیمات درس |
| `reports/periodic/` | بازهٔ تاریخ، یادداشت، مدل گزارش، متن، HTML، فیلتر و خروجی |
| `pwa/` | manifest و کنترل نصب/به‌روزرسانی |
| `styles/` | استایل‌ها به تفکیک اجزا؛ فونت‌های آفلاین در `fonts.css` |
| `legacy/` | رابط سازگار موجود: صفحات، جلسات، برنامهٔ هفتگی، گزارش و ورود داده |
| `workspace/` | دوره‌ها، state، ذخیره، پیش‌نویس، پشتیبان، تاریخچه و تنظیمات |

## قرارداد ساخت

`source-map.json` ترتیب فایل‌های هر خروجی را مشخص می‌کند. منابع `workspace/` داخل
یک scope مشترک و منابع `legacy/` در محیط classic مرورگر ترکیب می‌شوند. این قرارداد
برای حفظ APIهای موجود و بسته‌بودن state خصوصی دوره‌ها نگه داشته شده است؛ این فایل‌ها
ES module مستقل نیستند. هر فایل، یک مسئولیت موضوعی دارد و محدودهٔ مشترک آن در manifest مشخص است.

فایل‌های `ui/course/` داخل factory تنظیمات درس و فایل‌های `reports/periodic/` داخل
scope گزارش دوره‌ای قرار می‌گیرند. استایل‌ها نیز با حفظ ترتیب cascade ترکیب می‌شوند.

برای افزودن یک فایل، آن را در ترتیب مناسب `source-map.json` ثبت کنید. ساخت، فایل
منبع ثبت‌نشده، منبع تکراری یا خروجی نامعتبر را رد می‌کند. برای output جدید باید
ارجاع آن در HTML هم اضافه شود؛ cache و نسخهٔ PWA هنگام build محاسبه می‌شوند.

## چرخهٔ توسعه

1. فایل موضوعی مناسب را در `src/` تغییر دهید.
2. `npm run build` را اجرا کنید.
3. `npm test` را اجرا کنید؛ برای تست واحد تنها، `npm run test:unit` کافی است.
4. برای اجرای محلی `npm run dev` را اجرا کنید.

نام storeها، کلیدهای ذخیره، نسخهٔ schema و قرارداد backup به داده‌های قبلی وابسته‌اند.
تغییر آن‌ها نیازمند migration و تست سازگاری است. آزمون‌ها فقط دادهٔ ساختگی و پروفایل
مستقل مرورگر را به کار می‌برند.
